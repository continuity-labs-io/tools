Click My Applications in that left sidebar (or go directly to [https://cloud.ouraring.com/oauth/applications](https://cloud.ouraring.com/oauth/applications) / [https://developer.ouraring.com/applications](https://developer.ouraring.com/applications)).

Click Create New Application.

Fill in the minimal required fields:

Application Name: Local Telemetry CLI (or whatever you like)

Redirect URIs: Enter exactly http://localhost:8765/callback

Save the application and copy your Client ID and Client Secret.
